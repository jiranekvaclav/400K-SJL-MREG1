## Zjištění Codexu ze čtení složky (2026-06-12)

- Ve složce jsou kompletní podklady pro migraci: `index.html`, `data.json`, tři n8n exporty, dva VTT přepisy se summary, dashboard mockup a dokumentace platformy.
- `index.html` je velký statický dashboard v jednom souboru; začíná znakem `=` před `<!DOCTYPE html>`, obsahuje CSS/JS inline, projektové karty, KPI, filtry a chat panel Hynek.
- `data.json` má hlavní datovou strukturu: `meta`, `projekty`, `milniky`, `kpi`, `schuzky`, `poznamky`. Obsahuje 13 projektů, 79 milníků, 4 KPI a historická data ze schůzek.
- n8n workflow `400K MREG1 - Master Dashboard.json` skládá dashboard z Asany, statusů, tasků, milníků, KPI Excelu ze SharePointu, LLM briefu a generuje HTML.
- n8n workflow `400K MREG1 - Zpracování přepisů v3.json` načítá VTT z GitHubu, parsuje a čistí přepis přes Claude a přidává strukturované výstupy do `data.json`.
- n8n workflow `400K MREG 1 - Chat webhook.json` obsluhuje chat Hynka nad `data.json` přes webhook a Claude API.
- V exportech jsou reference na n8n credentials (`asanaApi`, `githubApi`, `googleApi`, `microsoftSharePointOAuth2Api`, Anthropic header), ale nebyly nalezeny přímo vypsané tajné hodnoty tokenů.
- Cílová aplikace má podle posledního zadání nahradit GitHub/n8n proces: Asana bude automatický zdroj, VTT a ostatní data se budou nahrávat ručně v UI, sezóna je Q4 aktuálního roku.
